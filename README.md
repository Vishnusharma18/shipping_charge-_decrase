# Vishnu Target Shipping Optimizer

Target-based Meesho image optimizer.

- Upload one product image.
- Set minimum and optional maximum shipping.
- Variations applied automatically: gradient background, border, size, white background, emoji overlay, sale badge.
- Candidates generated in parallel batches and tested fast on Meesho supplier catalog page.
- Stops immediately when displayed shipping is inside the target range.
- Unlimited use — no trial lock.
